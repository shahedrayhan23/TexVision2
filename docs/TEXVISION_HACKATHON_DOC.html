AI-Powered Fabric Defect Detection System

NITER Innovate Hackathon 2026

MD. Shahed Rayhan | CS 2304023 | North International University (NITER)

1️⃣ Problem Statement

Bangladesh's RMG industry ($40B+ exports) faces critical challenges:
  • Slow Inspection: 5-10 minutes per fabric piece manually
  • Low Accuracy: Only 70-80% defect detection rate
  • High Cost: $0.50-1.00 per inspection
  • No Real-time Data: Cannot track quality trends

Annual Loss: $2-3 Billion

2️⃣ Our Solution

TexVision: AI-powered mobile app for instant fabric defect detection
  • 📱 Inspector captures fabric photo with smartphone
  • 🤖 AI analyzes image in 2-3 seconds
  • 🎯 Detects defects with bounding boxes
  • 📊 Manager reviews and approves/rejects

8️⃣ AI Detection Methods

Mode 1: YOLO (Production)

  • YOLOv8 deep learning model
  • Highest accuracy (98%+)
  • Requires trained model file

Mode 2: Heuristic CV (Demo)

  • OpenCV classical computer vision
  • Works immediately - no model needed
  • Perfect for hackathon demos
💡 Key Innovation: TexVision works in offline mode without any cloud services or trained models - perfect for demos!

9️⃣ Quick Setup

Backend (5 minutes):

1. Clone repo 2. pip install -r requirements.txt 3. uvicorn app.main:app --reload

Mobile App (5 minutes):

1. cd mobile 2. npm install 3. npx expo start
